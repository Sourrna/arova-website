# AROVA Brand Guidelines

## Logo

### Lockups
- **Primary Latin wordmark**: `public/images/logo/arova-wordmark.svg`
- **Persian wordmark**: `public/images/logo/arova-persian.svg`
- **Combined bilingual lockup**: `public/images/logo/arova-combined.svg`
- **Standalone symbol**: `public/images/logo/arova-symbol.svg`
- **Dark variants**: `arova-wordmark-light.svg`, `arova-symbol-dark.svg`
- **Favicon**: `public/favicon.svg`

### Clear space
Minimum clear space around the logo equals the height of the letter "A" in the wordmark.

### Minimum size
- Digital: 24px height
- Print: 10mm height

## Colors

| Token | Hex | Use |
|-------|-----|-----|
| Obsidian | #141414 | Primary dark surfaces |
| Graphite | #202124 | Secondary dark panels |
| Burgundy | #5B1E2D | Primary brand accent |
| Wine | #35131D | Deep burgundy surface |
| Ivory | #F2EFE9 | Main light background |
| Silver | #BFC1C5 | Neutral accent |
| Muted Gray | #92949A | Secondary text |
| White | #FFFFFF | High-contrast text |

## Typography

- **Persian**: Vazirmatn
- **Latin**: Inter
- **Fallback**: system-ui, sans-serif

## Usage

- Burgundy is an accent, not a background color.
- Maintain WCAG AA contrast for body text and controls.
- Do not stretch, rotate, or recolor the logo.
- Use the one-color version on single-color backgrounds.

## Content Rules

- Persian is the default language.
- No fabricated client logos, testimonials, or metrics.
- Draft content must be marked clearly in source files.
